Pin Stats Tracker

A personal Pinterest analytics tracking tool

About the Project

Pin Stats Tracker is a personal project designed to help organize and monitor Pinterest Pin performance over time.

The tool is intended for use with the owner's Pinterest business account. It helps track available analytics, organize results in Google Sheets, and compare Pin performance over time.

Analytics

Depending on the data made available through Pinterest's API, the tracker may organize metrics such as impressions, engagements, saves, Pin clicks, and outbound clicks.

Privacy

This project is intended for personal use. Pinterest data is used only for the purpose of maintaining the owner's private analytics spreadsheet.
